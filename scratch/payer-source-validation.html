02 — How this was tested

Methodology

No source was marked usable from a search snippet or a vendor's description of itself. Every claim below is backed by one of these four techniques.

requests

Direct HTTP calls to index pages, HTML listings, and PDF endpoints — status code, content-type, and size logged for every hit.

BeautifulSoup

Parsed HTML link structures, meta tags, and page text to find discovery indexes and per-policy structured metadata.

pypdf

Extracted full text from coverage-policy and bulletin PDFs to confirm sections, dates, and CPT/ICD-10 code tables actually exist.

Playwright

Loaded pages in headless Chromium and captured real network traffic — the DevTools equivalent — to find data feeds hidden behind JS widgets.

03 — Payer 1

Aetna

Public clinical policy bulletins gave clean structured metadata but no visible changelog — until a captured network request exposed the JSON feed behind Aetna's own "What's New" widget.

Individual CPB detail pages

green
aetna.com/cpb/medical/data/{range}/{number}.html

Clinical coverage criteria per procedure — medical necessity rules, exclusions, and applicable CPT/ICD-10 codes. Every meta tag below was confirmed on 9 tested CPBs (0011, 0016, 0194, 0232, 0722, 0735, 0805, 0863, 0934).

"What's New" data feed (found via network capture)

yellow
aetna.com/content/services/aetna/xmlfilter?source=…mcpb-changes.xml…

Not visible in a plain HTML fetch — only surfaced by loading the page in headless Chromium and reading real network requests. Public JSON, no auth: the same endpoint the page's own dropdown widgets call. Cascading filter: status → month → date → results.

status: New/Revised/Updated/Deleted date url
filterValues=02-Revised → 217 entries Cross-check: CPB 0863 listed as Revised on 07/23/2026 — exactly matches its lastReviewDate meta tag above.

Undocumented internal endpoint, not a published API — no SLA, could change without notice. Window observed was a rolling ~4 months (Apr–Aug 2026), not full history.

Cigna

The strongest source set found so far: public medical policies each carry a genuine dated changelog, and a monthly cross-policy bulletin archives back to January 2023.

green

eviCore delegated UM guidelines

yellow
evicore.com/sites/default/files/clinical-guidelines/...

Cigna's own cover PDF names the delegated modules (CMM-200 ESI, CMM-201 Facet/MBB, CMM-203 SI Joint, CMM-208 RF Ablation, CMM-211 SCS/PNS); the CMM-200 guideline itself confirmed live on evicore.com. Filenames encode version + effective + publish dates.

The source document itself states this applies only "in certain markets" — must not be presented as universal Cigna policy.

06 — No LLM required

Calculation logic

Plain Python/SQL against the normalized fields above — nothing here needs a model call.

Guideline Changes count

COUNT(DISTINCT policy_number)
WHERE source IN ('Aetna','Cigna')
  AND change_date >= period_start

Changes since last check

new_signal =
  change_date > last_successful_check

-- Aetna: from the What's New feed
-- Cigna: from Revision Details or
--        bulletin posted_date

Payer × Procedure trend

GROUP BY payer, procedure
pct_change = (curr - prev) / prev * 100
IF prev == 0: label = "New Activity"

Payer-specific notes

Aetna feed window: ~4 months rolling
  -> fall back to per-CPB lastReviewDate
     for longer trends

Cigna bulletin archive: Jan 2023-present
  -> multi-year trends need no extra work
